# Como contribuir

1. Crie uma branch curta e descritiva.
2. Preserve a escrita em português e explique siglas na primeira ocorrência.
3. Todo exemplo deve validar entradas, evitar janelas gráficas e salvar resultados em `outputs/`.
4. Não envie pesos de modelos, imagens pessoais, dados biométricos ou datasets sem licença.
5. Execute `ruff check .`, `pytest` e `mkdocs build --strict` antes do Pull Request.

Ao propor uma nova técnica, inclua: objetivo, intuição, parâmetros, exemplo mínimo, limitações, riscos e pelo menos um exercício.
